# Firebase Remote Config — Pitfalls Catalog

14 entries from Firebase docs + community.

| # | Symptom | Cause | Fix | Source |
|---|---|---|---|---|
| 1 | Onboarding shows control variant on first run, then switches mid-flight | App started before fetch completed; activation happens later | Set in-app `setDefaults` for every key; OR show 1-2s splash that awaits `fetchAndActivate().timeout(2s)`, falls back to defaults on timeout | [Firebase real-time](https://firebase.google.com/docs/remote-config/flutter/real-time) |
| 2 | New values not reflected for 12h | Default `minimumFetchInterval` is 12h | Lower to 1h in code (server enforces ~1h prod floor regardless); use real-time `onConfigUpdated` for instant updates | [Firebase get-started](https://firebase.google.com/docs/remote-config/get-started?platform=flutter) |
| 3 | Real-time updates never fire | SDK below 4.0.0 OR `onConfigUpdated` listener cancelled before connection established | Ensure `firebase_remote_config` 4.0.0+; keep listener alive in app-scoped Provider (not widget-scoped) | [Firebase real-time](https://firebase.google.com/docs/remote-config/flutter/real-time) |
| 4 | `getInt('foo')` returns 0 even though console says 7 | Wrong type cast OR mismatch in `setDefaults` (you wrote `'foo': '7'` instead of `'foo': 7`) | Match default type to console type. Use `getValue('foo').asInt()` to be explicit | [Firebase docs](https://firebase.google.com/docs/remote-config/get-started?platform=flutter) |
| 5 | Different values seen by users at the same time | Conditions in console (country, app version, user property, percentile) — by design | Document; verify by setting test user properties and audience membership | [Firebase parameters](https://firebase.google.com/docs/remote-config/parameters) |
| 6 | App startup blocked 30+ seconds on bad network | `fetchAndActivate` awaited with no timeout | Use `unawaited()` OR `.timeout(Duration(seconds: 5))`, fall back to defaults | [Firebase docs](https://firebase.google.com/docs/remote-config) |
| 7 | `RemoteConfigUpdate` storm during a console rollout | Many updates in short window | In `onConfigUpdated` listener, debounce or check `event.updatedKeys.intersection(myKeys).isNotEmpty` before activating | [Firebase real-time](https://firebase.google.com/docs/remote-config/flutter/real-time) |
| 8 | A/B test results show 0 conversions | Variant property not set on Analytics user, OR Analytics consent denied | Mirror chosen variant via `setUserProperty`; ensure Consent Mode v2 grants `analytics_storage` | [Firebase A/B](https://firebase.google.com/docs/ab-testing/abtest-config) |
| 9 | Remote Config kill switch doesn't take effect immediately | App caches activated config; only activates on next `activate()` call | Use real-time listener calling `activate()` inside; OR explicitly call `fetchAndActivate` on app foreground | [Firebase real-time](https://firebase.google.com/docs/remote-config/flutter/real-time) |
| 10 | Force-update gate fails for users on planes / no network | Treating `min_supported_build` from RC as authoritative without offline fallback | `setDefaults({'min_supported_build': 1})` — never block users on remote when offline | [Firebase docs](https://firebase.google.com/docs/remote-config) |
| 11 | Memory leak with multiple `onConfigUpdated.listen` calls | Listeners never cancelled across screens | Subscribe ONCE at app scope (Riverpod Provider, not widget); cancel via `subscription.cancel()` on `ref.onDispose` | [Firebase real-time](https://firebase.google.com/docs/remote-config/flutter/real-time) |
| 12 | Real-time updates stop after backgrounding | The SDK pauses connection in background — by design | Resumes automatically on foreground; if you need while-backgrounded updates, send an FCM data message instead | [Firebase real-time](https://firebase.google.com/docs/remote-config/flutter/real-time) |
| 13 | 20M concurrent connection limit hit | Only at huge scale (millions DAU) | Falls back to standard fetch automatically; otherwise throttle with random jitter on listener attach | [Firebase real-time](https://firebase.google.com/docs/remote-config/flutter/real-time) |
| 14 | Personalization features show for users who declined consent | RC condition based on user property that itself was set under non-consented analytics | Don't gate consent UI itself on RC; for region-specific compliance flags, hard-code by `Locale`/`Country` | [Firebase docs](https://firebase.google.com/docs/remote-config) |
