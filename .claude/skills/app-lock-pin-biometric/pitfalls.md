# App Lock — Pitfalls Catalog

production Bug 3 production runundan + Flutter docs + OWASP.

| # | Symptom | Cause | Fix | Source |
|---|---|---|---|---|
| 1 | Face ID prompt → success → ekran açılır → hemen tekrar Face ID prompt → sonsuz döngü | `didChangeAppLifecycleState`'te HER `resumed`'da `controller.lock()` çalışıyor. Face ID dialog'u açılması app'i `inactive` yapar, kapanması `resumed` döndürür — gerçek bg dönüşü gibi algılanır | `_lastMeaningfulState` field'ı (sadece `paused` ve `resumed` izle); sadece `paused → resumed` geçişinde `lock()` çağır. `inactive → resumed` SKIP | [Flutter AppLifecycleState](https://api.flutter.dev/flutter/dart-ui/AppLifecycleState.html) |
| 2 | Lockout sayacı (`30s kaldı`) tickle güncellenmez; geçince PIN pad disable kalır | State değişmediği için widget rebuild olmaz; `lockedUntilEpochMs` sadece field, time-based değil | `Timer.periodic(Duration(seconds: 1), (_) => setState(() {}))` initState'te; `dispose()`'da iptal et | empirical |
| 3 | `showModalBottomSheet`'te `ref.watch(myProvider)` rebuild tetiklemez | Modal kendi `ModalRoute`'unda; parent widget'ın `WidgetRef` abone değil | Modal builder'ı `Consumer(builder: (ctx, ref, _) => ...)` ile sar. Modal kendi scope'unu kullanır | [Riverpod docs](https://riverpod.dev/docs/concepts/reading) |
| 4 | iOS Face ID device'da fingerprint ikonu görünür (UX yanlış) | Generic ikon kullanılmış; platform/biometric tipi sorgulanmamış | `LocalAuthentication().getAvailableBiometrics()` → `BiometricType.face` varsa `Icons.face_rounded`, yoksa `Icons.fingerprint_rounded` | [local_auth docs](https://pub.dev/packages/local_auth) |
| 5 | iOS 26 cold-start sonrası ilk `authenticate()` sessizce false döner | iOS 26 `LocalAuthentication` framework transient bug (Apple radar) | PIN pad fallback otomatik göster; kullanıcı sol-alt biometric ikona basıp retry edebilsin. Opsiyonel: 100ms gecikme + 1 internal retry | Apple radar |
| 6 | Cold-start'ta önce content (Dashboard) flash, sonra lock screen | Storage henüz okunmadı, `state.initialized=false` → gate `isLocked` false döner → content render → init bitince lock | `preInitCover = hasSession && !state.initialized` — initialized olana kadar Scaffold(black) overlay göster | empirical |
| 7 | Başka kullanıcı login olduktan sonra önceki PIN hâlâ aktif | Sign-out'ta storage temizlenmemiş | `supabase.auth.onAuthStateChange` listener'da `event == signedOut` ise `controller.clearOnSignOut()` — secure_storage'daki tüm app-lock key'lerini sil | empirical |
| 8 | Onboarding/login ekranlarında kilit prompt çıkıyor | Gate `state.enabled` kontrol ediyor ama session yok | `shouldLock = hasSession && state.enabled && state.isLocked` — session olmadan kilit gösterme | empirical |
| 9 | iOS app-switcher önizlemede içerik görünüyor (privacy leak) | Flutter overlay `inactive` state'te show edilmemiş | `AppLockGate`'te `inactive`/`paused`/`hidden` için `_PrivacyCover` widget göster. Defense-in-depth için iOS AppDelegate `applicationWillResignActive`'da native `UIVisualEffectView(.dark)` ekle | [Apple docs](https://developer.apple.com/documentation/uikit/uiapplicationdelegate/1622950-applicationwillresignactive) |
| 10 | Android BiometricPrompt crash: `MissingPluginException` veya `Plugin requires FlutterFragmentActivity` | Default `MainActivity` `FlutterActivity` extend ediyor; `local_auth` Android için `FlutterFragmentActivity` gerektirir | `android/app/src/main/kotlin/.../MainActivity.kt`'i `class MainActivity: FlutterFragmentActivity()` olarak değiştir | [local_auth Android setup](https://pub.dev/packages/local_auth#android-integration) |
| 11 | PIN compare timing leak (brute-force assist) | `pinHash == storedHash` — early-exit Dart string compare | Constant-time compare: `result \|= a[i] ^ b[i]` loop ile, sonunda `result == 0` | [OWASP timing attack](https://owasp.org/www-community/attacks/Timing_attack) |
| 12 | PBKDF2 iteration sayısı düşük (1000-10000) | Hızlı geliştirme için bırakılmış | OWASP 2023: minimum 120000 iter HMAC-SHA256. Cold-start +~150ms ama brute-force pratikte imkansız | [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#pbkdf2) |
