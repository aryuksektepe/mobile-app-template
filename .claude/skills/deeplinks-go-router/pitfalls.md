# Deep Links — Pitfalls Catalog

16 entries from Apple/Google docs, Branch.io guides, Flutter GitHub issues.

| # | Symptom | Cause | Fix | Source |
|---|---|---|---|---|
| 1 | Universal Links open Safari instead of app | AASA served as `application/octet-stream` or with `.json` extension or via redirect | Serve at exact path `/.well-known/apple-app-site-association` (no extension), `Content-Type: application/json`, no 301/302 | [Branch AASA guide](https://www.branch.io/resources/blog/what-is-an-aasa-apple-app-site-association-file/) |
| 2 | AASA changes don't take effect for hours | Apple CDN caches AASA up to 7 days (iOS 14+) | In debug, append `?mode=developer` to the entitlement; for production, force re-fetch via `swcutil`; verify via `https://app-site-association.cdn-apple.com/a/v1/<domain>` | [Apple Dev Forums](https://developer.apple.com/forums/thread/699401) |
| 3 | Android App Links open chooser instead of app directly | `android:autoVerify="true"` missing OR fingerprint mismatch with Play App Signing | Use Play Console → App Signing fingerprint (NOT local keytool); run `pm get-app-links <pkg>` to confirm `verified` | [Android docs](https://developer.android.com/training/app-links/verify-applinks) |
| 4 | Flavors break App Links — only release verified | Each flavor has different package name + cert | Multi-entry `assetlinks.json` array, one per package_name, each with full SHA256 list (including Play signing) | [Android configure assetlinks](https://developer.android.com/training/app-links/configure-assetlinks) |
| 5 | Deep link arrives at `/` then jumps to target | go_router renders initial location before initial-link is processed | Capture `getInitialAppLink()` BEFORE `runApp`; gate router on splash until processed | [GH flutter#142988](https://github.com/flutter/flutter/issues/142988) |
| 6 | Deep link to gated route triggers infinite redirect | Redirect chain `/promo → /login?return=/promo → /promo → ...` | Always check `if (loc.startsWith('/login')) return null;` early in redirect | community |
| 7 | URLs with `javascript:`/`data:` schemes crash app | Trusting `Uri` from incoming link without scheme check | Whitelist scheme `https` only; reject everything else | OWASP MASVS |
| 8 | SQL/path injection via deep-link param | Param passed straight to query | Validate IDs strictly (UUID/integer regex); never interpolate directly | OWASP |
| 9 | App opens but back button exits to home screen | go_router's `go()` clears stack; user expected to return to inbox | Use `push()` for context-preserving deep links, or pre-seed back stack via `ShellRoute` | [Medium guide](https://medium.com/@pinky.hlaing173/handling-deep-links-in-flutter-without-losing-navigation-using-app-links-over-go-router-45845bc07373) |
| 10 | iOS Universal Link works in Safari but not in Notes/Mail | Apple delegates 24h after first AASA upload; CDN warming | Wait, force-update via developer mode entitlement, or use `xcrun simctl openurl` to test | [Flutter cookbook](https://docs.flutter.dev/cookbook/navigation/set-up-universal-links) |
| 11 | Long-press → "Open in App" missing | iOS: AASA `details.appIDs` typo (must be `TEAMID.bundle.id` exact) | Verify via Apple's developer mode CDN URL | community |
| 12 | Cold-start link fires twice | Listening to `uriLinkStream` AND consuming `getInitialAppLink()` for the same link | Treat them as mutually exclusive — `getInitialAppLink()` returns the one that opened the app; stream is only for warm/post-launch | [app_links docs](https://pub.dev/packages/app_links) |
| 13 | go_router stack-clears legitimate user navigation | go_router rebuilds the entire stack on `replace`; `app_links` calls during normal navigation | Disable Flutter's default deep-link plumbing in Info.plist & AndroidManifest if you want full control with `app_links` | [Medium guide](https://medium.com/@pinky.hlaing173/handling-deep-links-in-flutter-without-losing-navigation-using-app-links-over-go-router-45845bc07373) |
| 14 | Deferred deep link lost after install (FDL replacement) | No SDK installed; iOS clipboard prompt scares users | Use Branch NativeLink, AppsFlyer OneLink, or build clipboard fallback with explicit "we copied your invite code, paste it here" UX | [Tapp FDL guide](https://www.tapp.so/firebase-dynamic-links-deprecation-guide/) |
| 15 | `intent-filter` `host` typo silently breaks verification | Typo in `android:host="exmaple.com"` | Always copy host from production URL; run `pm verify-app-links --re-verify` after build | [Android docs](https://developer.android.com/training/app-links/verify-applinks) |
| 16 | iOS 14 Private Relay breaks IP-based deferred links | Private Relay anonymizes IP that fingerprint matching used | Switch to Branch NativeLink (clipboard-based with user consent) or first-party login linking | [Branch NativeLink](https://help.branch.io/developer-hub/docs/nativelink-deferred-deep-linking) |
