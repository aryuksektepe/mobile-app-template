# Asset Preparation — Sizes + Transparency Cheatsheet

## Splash logo
- **`assets/splash/logo.png`** — primary centered logo
  - Size: ≥ 512×512, ideally 1024×1024
  - PNG with transparent background
  - Single color or limited palette (renders flat on light + dark)

- **`assets/splash/logo_dark.png`** — dark variant
  - Same dimensions
  - Usually white-on-transparent

- **`assets/splash/android12_icon.png`** — Android 12+ splash icon
  - Size: **1152×1152** (the OS clips to a circle ~~864×864 visible~~ — keep brand inside)
  - PNG with transparent background
  - Should be the brand mark only (no wordmark — Android 12 splash has separate `branding:` slot)

## Launcher icon
- **`assets/icon/icon_1024.png`** — master square
  - Size: exactly 1024×1024
  - **iOS does NOT accept transparency** in the App Icon — use a solid background

- **`assets/icon/foreground.png`** — Android adaptive icon foreground
  - Size: 1024×1024
  - Padding: ~1/3 around the brand (Android masks edges in circle/squircle/etc.)
  - PNG with transparent background (safe area = inner 432×432 of a 1024×1024 canvas)

- **`assets/icon/monochrome.png`** — Android 13 themed icon
  - Size: 1024×1024
  - **WHITE on transparent** — Android tints to match wallpaper
  - Same padding as foreground

## Notification icon (separate from launcher — see `notifications-fcm`)
- Path typically: `android/app/src/main/res/drawable-{hdpi,mdpi,xhdpi,xxhdpi,xxxhdpi}/ic_notification.png`
- **WHITE on transparent** PNG (Android paints a silhouette; non-transparent = white square bug)
- Generated by Android Studio → Image Asset Studio → Notification Icons

## RTL safety
- Splash logo must be **centered** (not anchored to start/end), else flips in Arabic/Hebrew locales.
- App icon never flips (Apple/Android render LTR regardless of locale).

## Color discipline
- Splash `color` (and `color_dark`) — pick a color from your design-system tokens (not arbitrary). Cross-reference `.project/design-system.md`.
- iOS LaunchScreen.storyboard is regenerated by `flutter_native_splash:create` — don't hand-edit it; re-run the tool.
