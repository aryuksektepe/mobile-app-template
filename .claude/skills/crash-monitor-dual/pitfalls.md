# Crash Monitoring (Crashlytics + Sentry) — Pitfalls Catalog

14 entries from Firebase docs, Sentry docs, and FlutterFire issues.

| # | Symptom | Cause | Fix | Source |
|---|---|---|---|---|
| 1 | Both services report the same crash twice | Both `FlutterError.onError` and `PlatformDispatcher.onError` chained without dedup | Accept duplication as cost of dual setup. Use Sentry "Inbound Filters" or fingerprinting if noisy. Or assign primary owner per type: Crashlytics for native, Sentry for Dart errors | [Sentry filtering docs](https://docs.sentry.io/platforms/flutter/configuration/filtering/) |
| 2 | Crashlytics shows obfuscated stack `xxx.dart:1` | Built with `--obfuscate --split-debug-info` but symbols not uploaded | `firebase crashlytics:symbols:upload --app=APP_ID PATH/TO/symbols`; for iOS use Flutter ≥3.12 + Crashlytics plugin ≥3.3.4 for auto-upload | [Firebase deobfuscated reports](https://firebase.google.com/docs/crashlytics/flutter/get-deobfuscated-reports) |
| 3 | Sentry stack also obfuscated | `sentry_dart_plugin` not configured or auth token missing | Add `sentry:` block to pubspec; set `SENTRY_AUTH_TOKEN` env var; build with `--obfuscate --split-debug-info=build/symbols` then run plugin | [Sentry dart-plugin docs](https://docs.sentry.io/platforms/dart/guides/flutter/debug-symbols/dart-plugin/) |
| 4 | iOS dSYMs missing | Bitcode or "Debug Information Format" set to DWARF only (no dSYM) | In Xcode → Build Settings → Debug Information Format = "DWARF with dSYM File" for Release | [Firebase Crashlytics get-started](https://firebase.google.com/docs/crashlytics/flutter/get-started) |
| 5 | Native (NDK) Android crashes invisible in Sentry | Sentry Flutter doesn't capture Android NDK signals by default in older versions | Enable `enableNdk: true` in Sentry options (default true on SDK ≥7) — but Crashlytics is still more reliable for NDK | [Sentry options](https://docs.sentry.io/platforms/flutter/configuration/options/) |
| 6 | Crashes flooding production from debug builds | `setCrashlyticsCollectionEnabled` left at default | Gate with `!kDebugMode` after init; same for Sentry via `o.debug = kDebugMode` and lower `tracesSampleRate` in debug | [Firebase customize](https://firebase.google.com/docs/crashlytics/customize-crash-reports) |
| 7 | PII appearing in Sentry events (emails, tokens) | `sendDefaultPii: true` (the default in some Sentry SDK versions) or no `beforeSend` | Set `sendDefaultPii: false` and add `beforeSend` to strip user fields, request bodies, query strings — see [snippets/sentry_scrubber.dart](snippets/sentry_scrubber.dart) | [Sentry sensitive data](https://docs.sentry.io/platforms/flutter/data-management/sensitive-data/) |
| 8 | `setUserIdentifier(email)` violates KVKK | Email is direct PII | Pass an opaque hash (SHA-256 of user UID); see [snippets/identify_user.dart](snippets/identify_user.dart) | [Firebase customize](https://firebase.google.com/docs/crashlytics/customize-crash-reports) |
| 9 | Test crash via `FirebaseCrashlytics.instance.crash()` doesn't show up | App must be relaunched; crash is uploaded on next start | Crash, restart app, wait up to 5 min. Sentry shows up faster (~1 min) | [Firebase test implementation](https://firebase.google.com/docs/crashlytics/test-implementation) |
| 10 | `runZonedGuarded` recommended in old tutorials still being used | Pre-Flutter 3.3 pattern; now `PlatformDispatcher.instance.onError` is canonical | Remove `runZonedGuarded`; use the two direct hooks | [Firebase Crashlytics get-started](https://firebase.google.com/docs/crashlytics/flutter/get-started) |
| 11 | Releases not associated with crashes | `release` not set or inconsistent across services | Use `package_info_plus` to read version+build, set `release` in Sentry; `setCustomKey('build_number', ...)` in Crashlytics | [Sentry options](https://docs.sentry.io/platforms/flutter/configuration/options/) |
| 12 | `recordError` calls drop on first run before init completes | Errors thrown during init bypass handlers | Wire error handlers as the very first thing after `WidgetsFlutterBinding.ensureInitialized()`; queue early errors if needed | [Firebase get-started](https://firebase.google.com/docs/crashlytics/flutter/get-started) |
| 13 | Obfuscation map files (`obfuscation.map.json`) not retained | Lost between CI runs | CI must persist `build/symbols/` and `obfuscation.map.json` as build artifacts; otherwise future deobfuscation impossible | [Sentry debug symbols](https://docs.sentry.io/platforms/dart/guides/flutter/debug-symbols/) |
| 14 | Sentry breadcrumbs missing route changes | `SentryNavigatorObserver` not added | Add to `MaterialApp.navigatorObservers` and to `go_router` observers | [Sentry Flutter docs](https://docs.sentry.io/platforms/flutter/) |
