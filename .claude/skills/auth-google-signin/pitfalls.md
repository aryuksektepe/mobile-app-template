# Google Sign In — Pitfalls Catalog

17 entries from `google_sign_in` v7 migration guide + Flutter GitHub issues.

| # | Symptom | Cause | Fix | Source |
|---|---|---|---|---|
| 1 | `PlatformException(sign_in_failed, ApiException: 12500)` on Android release only (works in debug) | SHA-1 mismatch — Play App Signing uses a different cert than your upload keystore | Copy SHA-1 + SHA-256 from Play Console → App Signing → "App signing key certificate"; paste into Firebase Console; redownload `google-services.json` | [Yasin Ilhan](https://medium.com/@yasinilhan/how-to-fix-flutter-google-sign-in-plugin-12500-error-ed2de7f5276f) |
| 2 | `GoogleSignInException(clientConfigurationError)` on first call | Forgot to await `GoogleSignIn.instance.initialize()` before any other method | Always `await initialize(...)` in `main()` BEFORE `runApp` | Isaac Adariku migration guide |
| 3 | Works debug, fails on Play Store with `Account reauth failed` (code 16) | App Bundle signed by Play, fingerprint not registered | Add Play App Signing SHA (same as #1) | [GH flutter#174744](https://github.com/flutter/flutter/issues/174744) |
| 4 | `idToken` returned but `accessToken` always null | v7 separates auth from authz; `accessToken` only available after `authorizationClient.authorizeScopes(...)` | Explicitly request scopes; for Firebase Auth alone you don't need `accessToken` (idToken is sufficient) | DEV community v7 article |
| 5 | `GoogleSignInExceptionCode.canceled` on Android even when user didn't tap cancel | Credential Manager bottom sheet auto-dismissed (no Google account on device, or stale state) | Catch as soft cancel; show "Add a Google account or try again" UI; do NOT show error toast | [GH flutter#172722](https://github.com/flutter/flutter/issues/172722) |
| 6 | `serverClientId is required on Android` exception | v7.1+ enforces this even when `google-services.json` is present | Pass the **Web** OAuth client ID (type 3) as `serverClientId` to `initialize()`. NOT the Android client ID. | [GH flutter#171462](https://github.com/flutter/flutter/issues/171462) |
| 7 | Account picker not shown on second sign-in (auto-signs in last user) | Credential Manager remembers selection | To force account picker, call `disconnect()` (not just `signOut()`) before `authenticate()` | [GH flutter#94109](https://github.com/flutter/flutter/issues/94109) |
| 8 | `account-exists-with-different-credential` Firebase error | User previously signed up via email/password (or Apple) using same address | Catch, ask user to sign in with original provider, then link Google: `currentUser.linkWithCredential(googleCred)` | Firebase docs |
| 9 | Web sign-in returns expired `accessToken` after 1 hour | v7 web doesn't auto-refresh `accessToken` | Catch 401 from Google API calls; re-request via `authorizeScopes` or use Firebase ID token instead | [Thomas Spillecke](https://medium.com/@thomas.spillecke/flutter-and-google-sign-in-for-web-applications-v7-2-0-a64b8e5b5a5c) |
| 10 | Web One Tap not appearing in Chrome 139+ | FedCM mandatory since M139 (Aug 2025) — old GIS API removed | Update `gsi/client` script tag, ensure `use_fedcm_for_prompt: true`, add Permissions-Policy header `identity-credentials-get=*` | [Google FedCM blog](https://developers.googleblog.com/announcing-federated-credential-management-fedcm-beta-for-google-identity-services/) |
| 11 | Workspace user blocked: "your administrator has restricted access" | Google Workspace organization policy denies third-party app access | Document workaround: user must request admin approval; offer email/password as fallback | Workspace admin policy (well-documented) |
| 12 | "DEVELOPER_ERROR" / code 10 on Android | OAuth consent screen not configured (logo, privacy policy, homepage) | Fill in OAuth consent screen in Google Cloud Console; publish from Testing to Production | [copyprogramming](https://copyprogramming.com/howto/platformexception-platformexception-sign-in-failed-com-google-android-gms-common-api-apiexception-12500-null) |
| 13 | iOS sign-in opens Safari then nothing happens | REVERSED_CLIENT_ID URL scheme missing from Info.plist | Add `CFBundleURLTypes` with the REVERSED_CLIENT_ID from `GoogleService-Info.plist` | Firebase iOS docs |
| 14 | Tests crash because `GoogleSignIn.instance` not initialized | New singleton can't be mocked easily | Wrap in your own interface (e.g., `AuthClient`); inject via Riverpod; mock the interface in tests | testing best practice |
| 15 | Apple App Review rejection: "must offer Sign in with Apple" | Guideline 4.8: any third-party login on iOS → must also offer SIWA | Implement `auth-apple-signin` skill and show on iOS only | [Apple guidelines 4.8](https://developer.apple.com/app-store/review/guidelines/) |
| 16 | After `signOut`, calling `authenticate` shows the same Google account without prompt | `signOut` only clears in-process state, not the Credential Manager grant | Use `disconnect()` to revoke entirely, OR accept this as "remember me" UX | [Google disconnect docs](https://developers.google.com/identity/sign-in/android/disconnect) |
| 17 | Hot-restart breaks `authenticate()` with weird state | Singleton state survives hot restart but native side resets | Force a `signOut()` then re-`initialize` in dev only; not a production issue | community |
