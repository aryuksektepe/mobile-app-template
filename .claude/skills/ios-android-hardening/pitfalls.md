# Hardening — Pitfalls Catalog

10 entries from Flutter issue tracker, Firebase docs, R8 docs, Apple Xcode release notes.

| # | Symptom | Cause | Fix | Source |
|---|---|---|---|---|
| 1 | App debugs fine, release crashes immediately with `NoSuchMethodError` / `ClassNotFoundException` | R8 stripped a class accessed via reflection (Drift, json_serializable runtime, freezed sealed) | Add `-keep class your.pkg.** { *; }` for the model package OR specific class; re-run `verify-release-shrinking.sh` | [R8 docs](https://developer.android.com/build/shrink-code) |
| 2 | Crashlytics stack trace shows `MissingFile.dart:0` instead of method names | `--obfuscate --split-debug-info` was used but `.symbols` files never uploaded | Upload `build/symbols/<flavor>/<version>/*.symbols` to Crashlytics via `firebase crashlytics:symbols:upload` (per `crash-monitor-dual`) | [Flutter obfuscation](https://docs.flutter.dev/deployment/obfuscate) |
| 3 | iOS crash addresses show as hex (0x10043fa9c) instead of symbol names | dSYM not uploaded OR Strip Style was wrong | Set Xcode → Build Settings → Release: Strip Style = All Symbols, Debug Information Format = DWARF with dSYM File; upload dSYMs via Fastlane | [Apple dSYM docs](https://developer.apple.com/documentation/xcode/building-your-app-to-include-debugging-information) |
| 4 | Release APK is huge (~80MB) | `minifyEnabled false` / `shrinkResources false` — R8 not running | Enable both in `android/app/build.gradle` release block; add keep rules (snippets/proguard-rules.pro) | [Android shrinking guide](https://developer.android.com/build/shrink-code) |
| 5 | App size dropped but a feature crashes only in release | R8 stripped a JNI / MethodChannel handler class | Add `-keepclasseswithmembers class * { native <methods>; }` and the specific handler classes | [Android NDK reflection](https://developer.android.com/training/articles/perf-tips) |
| 6 | Logcat shows `java.lang.VerifyError: ... is missing class` | R8 minified a class that's still referenced — usually a transitive dependency | Use R8 `--enable-tracking` to find the call site; add a `-keep` for the class | [R8 trace](https://r8.googlesource.com/r8) |
| 7 | After flutter version bump, release crashes with `UnsatisfiedLinkError` on libflutter | Old engine .so referenced; gradle cache stale | `flutter clean && cd android && ./gradlew clean && cd .. && flutter build appbundle ...` | [Flutter release docs](https://docs.flutter.dev/deployment/android) |
| 8 | `--split-debug-info` files differ by build → symbol upload mismatch | Path includes timestamp / build number — symbols don't match the binary | Use a stable path: `build/symbols/<flavor>/<version>` (no build number in path); CI must persist these as artifacts | [Flutter symbol mgmt](https://docs.flutter.dev/deployment/obfuscate#read-an-obfuscated-stack-trace) |
| 9 | Mocked tests use `mocktail` — release breaks because mocks were never excluded from prod build | Test code accidentally referenced from prod (rare; happens when a util is in both `test/` and `lib/`) | Run `flutter pub deps` — confirm `mocktail` is in `dev_dependencies` not `dependencies` | Flutter docs |
| 10 | Play Store reject "App Bundle has unaligned uncompressed resources" | A pre-Android 6 .so resource isn't uncompressed-aligned by R8 | Update `android/app/build.gradle` `android.packagingOptions { jniLibs.useLegacyPackaging = false }` | [Android App Bundle docs](https://developer.android.com/guide/app-bundle/configure-base) |
